# Gradient Lab：本地渐变编辑器

这是独立可运行、可修改源码的学习实现。所有 JavaScript、GLSL、字体与颜色数据都在本地，不需要 colir.space 服务、iframe 或账号。

## 从哪里读起

1. `curve-field.js`：编辑 X/Y 一维曲线、色标位置、颜色数量，上传 GPU 纹理；画布曲线与侧栏小曲线共用数据。
2. `palette.js`：sRGB → OKLab → OKLCH、最短色相插值、色域压缩、色带 LUT。
3. `noise.js`：固定种子 xorshift32 生成 256×256 噪声纹理。
4. `shaders/effect.glsl`：从曲线得到标量、Global blend 混合、羽化、颗粒、色带映射。
5. `main.js`：WebGL 初始化、画布尺寸、导出图片、导入导出参数。
6. `bezier-grid.js` 与 `mesh-editor.js`：额外的二维贝塞尔网格，保留之前的网格编辑功能。

## 核心渲染流程

每个像素使用归一化坐标 `(u,v)`：

```text
X(u), Y(v)                         Catmull–Rom 曲线（可切换线性）
↓
mix(curve, sin(PI * uv)^feather, .2) 羽化，feather = UI 数值 / 100
↓
GlobalBlend(X, Y)                  12 种标量混合公式
↓
value += (hybridNoise - .5) * noise Noise = UI 数值 / 100
↓
OKLCH palette LUT[value]           4096 个 sRGB 采样
↓
附加网格颜色、点阵                  本学习版保留的扩展
```

关键区别：Global blend 混合的是两个曲线值；颗粒扰动的是色带坐标，不能简单用白噪点叠加到 RGB 上代替。源站 Feather 是标量场调节，不是通常的高斯模糊。

噪声混合比例为屏幕空间 47% + 曲线空间 53%，曲线空间缩放 75、抖动 0.25。固定种子 1337。GLSL 浮点精度可能造成细微噪声差别，不声称逐像素完全一致。

## 操作

- X / Y 按钮切换当前编辑曲线；拖动圆点、双击加点、右键删除内部点。
- 色带下方拖动色标，或输入 Position%；Hex 可直接输入颜色。
- 颜色数 2–20；可反转、均匀分布、打乱或删除色标。
- Feather 1–40、Noise 0–30，滑杆与数字框同步。
- Width / Height 64–4096 控制真实渲染和图片导出尺寸。
- PNG / WebP 导出本地图片，保存参数 JSON 可复现色带、曲线、尺寸、混合模式、羽化和噪声。
- JSON 暂不保存额外的二维网格形变和新增网格色点；导入时重置这两项。
- H 隐藏面板，空格播放或暂停；播放目前沿用本项目的域变形动画。

## 与源站的边界

已按公开可观察逻辑实现核心渐变链路和参数。配色模板随机策略、初始曲线、动画是本学习版实现。没有实现源站的完整 Distortion、Glitter、Patterns、PRO 滤镜、动画时间线或视频导出，也不宣称整站已一比一复制。点阵仍是本项目的固定规则网格，区别于源站 Glitter。

修改 effect.glsl 后，同步完整片元文件：

```sh
python3 scripts/assemble_shader.py
```

验证数学模块：

```sh
node tests/palette.test.mjs
node tests/bezier-grid.test.mjs
node tests/study.test.mjs
```


## 图片与视频导出（2026-09-18）

使用 `python3 server.py` 启动。支持 PNG、WebP、MP4、WebM，文件直接写入项目 `exports/`，页面显示路径和打开链接。MP4 需要本机 ffmpeg（当前已安装），采用 H.264/yuv420p 以兼容常见播放器。视频录制 1–60 秒，可选 30/60 fps，实际帧率受浏览器渲染性能影响；录制时请保持页面在前台。导出结束恢复原来的播放状态与时间，编辑辅助曲线不会录入。奇数画幅转 MP4 时会补齐到偶数尺寸。

## 可编辑点阵（2026-09-18）

点阵支持 0–2000 个点、颜色、圆点/方块/菱形/十字/圆环/四角星、1–30 像素大小、0–100% 不透明度。数量是全画布的实际形状数量；末行不足时只显示剩余数量。使用屏幕坐标，与颜色曲线变形分离。点阵设置写入 JSON，并由同一个 fragment shader 渲染到 PNG/WebP/MP4/WebM 中。

## 修改导出文件夹

在「导出位置」输入完整路径（支持 `~/Downloads/渐变作品`、空格和中文），点击「保存位置」。文件夹不存在时会创建，无法写入时显示错误；设置会记住，下次启动继续使用。修改只影响之后生成的文件，不移动旧作品。已有作品链接仍可打开。浏览器额外下载的副本遵循浏览器自身的下载设置。

### 系统文件夹选择器

「导出位置 → 选择文件夹…」打开 macOS 原生文件夹窗口，支持浏览磁盘、新建文件夹、选择及取消。确认后自动保存设置，取消不改变位置。系统窗口由本地 Swift/AppKit 小程序提供（源码 `scripts/choose-export-folder.swift`），首次启动时若缺少编译产物，会由服务自动编译到 `.runtime/`。

## 边缘颗粒修正

已核对源站公开 GPU shader 的 computeSceneColor：先混合 X/Y 得到色带坐标，再以屏幕噪声与曲线空间噪声的混合值扰动坐标，最后查询颜色 LUT。不是在输出 RGB 上增加灰度噪声。修正本地噪声纹理的半像素偏移以及 LUT 采样位置；旧参考网格模式改用 UV 扰动，纯色底不再叠加 RGB 噪点。旧网格的 UV 扰动是本项目适配，不是源站算法。颗粒在色带变化大的区域更明显，并非使用一张仅限轮廓线的遮罩。

## 光栅海报（2026-09-20）
新增独立的光栅海报模式：UV 网格量化形成阶梯边界，标量色阶映射到现有 OKLCH 色带，再叠加余弦柱面明暗、高光和静态印刷噪声。五组预设参考用户提供的海报质感，不复制文字排版。光栅数量、深度、网格、色阶、印刷颗粒均保存到 JSON；原图片/视频导出直接捕获同一 shader 画布。
